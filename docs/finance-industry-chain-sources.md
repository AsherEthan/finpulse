# 金融脉搏：产业链来源与运营口径

核验日期：2026-10-03。中国为主，兼顾全球。本轮新增20个订阅配置，其中19个已启用并完成采集，扬电履约入口因连续HTTP403暂停。配置包括：宏观3个、中国政府采购网1个、行业统计6个、公司披露9个、广期所仓单1个。原19个基础订阅之外，补充核验了工信部运行监测协调局电子信息栏目。配置数不代表已公开文章数或完整历史覆盖；产业链初始内容与综合财报分别按栏目发布。

## 五个产业主题

| 主题 | 首期机构与公司 | 重点指标及边界 |
|---|---|---|
| 能源与有色 | 国家统计局、国家能源局；广期所碳酸锂仓单与电池主题交叉观察 | 原煤、原油、天然气、发电量，生产资料价格，工业利润与库存。规上工业发电量和全社会用电量的统计总体不同；仓单只覆盖指定交割体系，不是社会总库存。其他交易所、品种尚未因此接通。 |
| 汽车与动力电池 | 乘联分会、中汽协、工信部；巨潮上的比亚迪、上汽、宁德时代原始披露 | 厂商生产、批发、终端零售、出口、锂电池产量。狭义乘用车与全部汽车分别保存；电池生产量不等于装车量，GWh不等于车辆数。公司快报保留未经审计等原文限定。 |
| 半导体 | 工信部、国家统计局、WSTS；巨潮上的中芯国际、中微 | 芯片实物产量、半导体销售金额、设备与项目经营进展。芯片块数不能代表先进制程或价值量；WSTS亚太区域不等于中国，自然月金额与三个月移动平均分开。扬电算力合同另列履约案例，订阅当前暂停，不作为已接通的芯片订单数据。 |
| 光伏与电力 | 国家能源局、工信部、国家统计局；巨潮上的隆基、晶科 | 多晶硅等材料价格、制造产量、发电装机和设备利用，以及公司投资、投产和财务披露。装机容量是期末存量，设备利用小时是累计指标；计划产能不能写成已投产产能。 |
| 消费与地产 | 国家统计局社零、房地产及工业数据；交通运输部物流周报 | 商品零售、开发投资、新开工、施工、竣工、销售、待售等原始指标，结合物流观察实际需求。名义金额、面积、企业数量和指数不能直接相加；港口、铁路、高速公路数据覆盖范围各异，物流变化不能单独证明消费或地产的因果变化。 |

国家统计局订阅同时跟踪工业增加值、利润、PPI、旬价、PMI、产能利用率、能源、社零和房地产。国家能源局跟踪用电及全国电力统计，交通运输部跟踪物流周报。行业6个订阅为乘联分会周报、月报，中汽协产销简析，工信部锂电与电子信息运行、运行监测协调局电子信息运行，WSTS历史销售报告；两个工信栏目可能重刊同一期，按报告期、内容及原始来源关联去重。公司9个订阅将汽车、电池、半导体、光伏的经营进展与综合财报分开，另保留已暂停的扬电合同履约配置。中国政府采购网当前范围是中央采购中标、成交公告，并非完整合同或付款库。

## 分类、标签与一手性

主栏目为披露与数据、产业链、政策、资金流、论文；一手性是独立来源属性。具体产销、订单、价格、库存、产能事实归产业链；完整财报及综合宏观摘要归披露与数据；规则及原文明确关联政策或公共投资的执行材料归政策；融资、申赎、跨境资金和流动性事实归资金流；有作者、方法和正式发表信息的学术论文、工作论文与机构研究报告归论文。论文研究的产业或政策议题保留为主题。官方统计不因发布机构身份自动成为政策，数据表和信心调查不自动归论文。

主题可交叉；另标上中下游、经营指标、实际或计划、履约阶段和统计周期。来源标签只表达订阅范围，文章标签按正文事实决定，每篇不超过6个。排除荐股、营销、传闻和无依据预测。

政府、交易所及公司原始披露使用T1；乘联分会、中汽协、WSTS等发布自身统计的行业协会使用T1_5，同时保留 `first_party=true`。一手性表示直接来自发布者，不表示政府统计、独立审计或多份独立证据。工信部转引统计局或协会测算时保留原始统计来源，不重复计作独立证据；巨潮只收公司原始文件，不把平台公司资料或第三方核查文件当公司经营事实。

## 每条稿件的最低核对

- **日期**：分别记录统计期间、原文发布时间、公司文件落款和取得时间。9月发布的上半年报告仍是上半年数据；网址日期不能代替页面日期。已核对的旬价页实际发布于9月24日，网址却含9月23日。工信部1—7月电子信息稿正文发布于8月31日，元数据却写9月2日：保存两者，展示优先正文可见时间，缺正文时不以其他时间替代。当前装机原文为7月末，不补写8月数据。
- **周期**：乘联周报标题的周窗口可能包含当月累计销量；不当完整自然月。NBS工业利润为年内累计，库存、应收账款为月末存量。PMI是季调后的调查扩散指数，产能利用率按价值量计算且未经季调；两者都不是订单金额或机械开机率。
- **履约**：订单→交付→验收→计费→收入确认→回款，每一步分别找公开证据，不保证固定顺序。签约或含税订单金额不能推算收入，计费不能证明已收现金。采购招标、中标、合同和付款同样分开；未取得后一阶段证据时保持未知。
- **单位与覆盖**：分清存量与新增、同比与环比、当期与累计、产量与销量、批发与零售、生产与装车。仓单“手”不直接改写为吨；仓库明细、小计和总计不能重复相加。空值、无日期占位和请求失败都不能发布成零库存。

公开只用短摘要和原文链接，关闭站内及分发全文。协会免费页面不等于完整历史、数据库或商业再分发许可。关联投资影响时明确是本站分析，并附依据，不从单项指标推出股价或利润预测。

## 初次展示的证据门槛

乘联周报零售、批发数值和工信部锂电产量已有本轮正文证据。中汽协本轮重验的是标题、日期及图片正文入口；产销具体数值须重新阅读原图后使用。当前可先写“8月汽车工业产销简析已发布”，不沿用未在本轮重核的数字。

WSTS的[报告入口](https://www.wsts.org/67/Historical-Billings-Report)与本轮实际取得的[XLSX原表](https://www.wsts.org/esraCMS/extension/media/f/WST/7771/WSTS-Historical-Billings-Report-Jul_2026.xlsx)是不同URL：订阅候选指向实际下载文件，摘要核对相同文件版本。表内统计期截至2026年7月，首次公开日期未查明，不能把7月末或下载日写成发布时间。订阅报告链接也不代表月度数值适配器已完成；未公布月份的空单元格或移动平均占位零值不得当作实际销售。

广期所按中国时区当天起最多回查7个自然日，使用明细日期和品种汇总确认最近有效统计日；接口成功、事件日历或周一至周五推算都不能证明当天有仓单数据。交易日下午3点是统计截止时间，不是已经核实的首次发布时间。以统计日和品种识别材料，不能因各期共用原文入口而混为同一条。
