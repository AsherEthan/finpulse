# 政策动态的阅读与核对

首页「精选」仍按原有编辑选择展示。政策入口在 `/all?category=policy`；政策主题默认展示全部已核对动态，并另列精选数量。采集到原始资料、通过核对公开、进入精选是三个不同状态。

## 标签、主题与事实

九个政策领域作为主题入口。标签保留检索用途；文号、发布机关、类型、地域、成文日、生效日和截止日期放入政策事实字段，不依靠标题猜测。

- 发布阶段：政策计划、征求意见、意见反馈、正式文件、配套细则。
- 法律效力：待生效、现行、部分失效、已废止、未知，并记录核对时点。
- 执行状态：未核实、已启动、有执行证据、已评估。

生效日已过不自动证明现行有效；正式文件有执行要求不等于资金已经发放。缺少原文依据的字段留空或标为未知。草案的意见截止日期单列，不充当生效日。

政策动态可同时限定一手信源、主题、标签和关键词，并分别选择发布机关、地域、阶段及类型。每组内多选为「或」，组与组之间为「且」；切换标签、搜索、分页保留筛选范围。接口的重复参数与页面一致，例如：

```text
/api/site/pool?category=policy&channel=firstParty&issuer=财政部&issuer=中国人民银行&stage=正式文件
```

## 版本与执行证据

每份文件可附原文附件、已核对的变更和相关原始材料。只有原文确立的关系才标为旧版、配套或反馈；同一主题的文件只能标为同主题。关系链并不要求每份政策都有完整的「草案→正式→执行→评估」线性流程。

住房金融案例关联居民购房贷款贴息、个人住房贷款管理及商品住房开发贷款管理，区分需求端贴息与供给端信贷管理。财政累计统计是观察数据，不能当作新政策的执行成效。下一步应查省级财政预拨、银行办理与实际贴息报表。

资本市场案例关联深交所2026年交易规则、官方修订说明、技术准备通知及施行材料。变更仅摘取已经读过的修订说明；市场成交量和做市效果仍须后续统计证明。

人工核对内容显示「摘要」「核对记录」。没有模型评分的人工内容保持空分数；补录事实不会改变已有精选资格。

## 来源覆盖

政策动态的「来源覆盖」列出最后尝试、最后成功、最近原文日期、采集窗口、新增与修订数、待核数及失败情况。无更新与失败分开；从未运行的配置不称为已接通。窗口有上限时明确提示；首次回灌被数量上限截断的资料在后续正常轮次补读，窗口以外的历史资料须另做回灌，不宣称完整覆盖。受原站限制的来源另列原因。

## 持续采集与审核

`WORKER_MODE=collection` 只消费免费的公开 HTTP 采集及正文提取任务，关闭 Jina 回退，不注册模型分析、付费社交采集、发布、报告或推送任务。每分钟调度到期来源，按来源自己的间隔检查。新资料进入后台待核队列，不凭规则生成分数或自动进精选。

此模式与完整 worker 使用同一队列，同一数据库只运行一种模式；切换模式会移除另一模式的定时任务。完整编辑流水线仍使用原有付费回执、预算和模型安全阀。

本机预览使用关闭模型、推送和提交的独立配置。网站上线前仍需配置运行服务、预算以及人工确认条款。

政策事实可在后台编辑，或用 `scripts/import-policy-facts.ts reviewed.json` 先核对导入批次，再加 `--apply` 写入。文件逐条提供原文 URL、当前资料修订号、政策字段和核对理由，导入经过版本检查和审计。未知字段不填；来源修订后的政策事实须重新核对。
