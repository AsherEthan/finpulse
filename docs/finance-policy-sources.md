# 金融脉搏：政策信息源与观察维度

核验日期：2026-10-03。中国为主，兼顾全球。现已配置60个官方来源（本轮新增52个），55个主题，并导入本地预览。来源配置在 `industry/sources.json`，受限或已替换的入口在 `industry/source-limitations.json`。已一次性采集10个来源、74条资料，经原文核对发布19篇，其中7篇列入精选。持续采集、真实模型和外部推送仍关闭。

## 1. 信息如何分类

政策主题、文件阶段、发布机构、地域与证据层级分别保存，不混成互斥分类。一条政策可以同时关联财政、产业、跨境等主题；“地方”是地域维度，“一手”是来源属性。

首页保留精选与原有全分类筛选；政策是全部动态中的一个分类。进入 `/all?category=policy` 后，可按九个政策主题（综合宏观、货币、财政、税收、金融监管、产业、房地产、贸易、跨境）和阶段、执行证据、地区标签组合筛选，搜索与分页保留范围。其他金融披露、产业链与资金流继续使用各自分类。

每个主题下跟踪三类证据：

1. **文件规则**：目标、规则、额度、对象、条件、生效安排。
2. **操作动作**：工具操作、债券发行、资金下达、许可、采购、处罚。
3. **执行与结果**：实际支出、资金使用、覆盖主体、项目进度与经营指标。指标变化本身不能证明某项政策的因果效果。

## 2. 可获取的八个维度

| 维度 | 优先获取的信息 | 判断边界 |
|---|---|---|
| 方向与形成 | 规划、规章制定计划、委员会例会、草案、起草说明、征求意见与反馈 | 计划和草案不能视为已经出台或生效 |
| 发布与效力状态 | 正式文件、文件类型、发文机关、文号、施行日期、有效法规目录、修订及废止 | 新闻发布、政策解读与正式文件分别保存；不凭新闻措辞判断效力 |
| 实质变化 | 与草案、前一版本相比修改的条款、数值、适用对象及例外 | 比较必须有原文版本和条款依据；缺旧版时标为未完成比较 |
| 工具与力度 | 利率、准备金、税率、补贴比例及上限、预算、额度、期限、配额、准入与资本要求 | 额度、操作量、实际使用量、存量、流量分别保存 |
| 适用范围 | 地区、行业、机构、业务、企业资格、商品编码及原产地等 | 原文未列企业时，行业关联属于本站分析，不能直接标为受益公司 |
| 时间与窗口 | 成文、发布、生效、过渡期、申报截止、到期、修订日期及统计观察期 | 不将上述日期合成一项；草案反馈期结束不代表正式文件必然发布 |
| 配套与执行 | 细则、问答、申报指南、资金下达、许可名单、采购中标、监管措施、处罚与整改 | 公示不等于拨付，批准不等于开工，要求整改不等于整改完成 |
| 评估与验证 | 预算执行、项目绩效、审计、行业与金融统计、延长或退出安排 | 关注不达标、延期与执行缺口；相关变化与政策因果解释分别保存 |

政策阶段不保证线性或完整公开。按证据关联计划、草案、反馈、正式文件、细则、操作、评估和修订；没有证据的环节保持空白。

## 5. 后续完整政策档案的最低字段

目前已实现原文链接、标题、来源机构、发布时间、主题及阶段/执行/地区标签。下列完整档案、条款参数和版本关联是后续目标，尚未增加专门的数据字段或自动比对流程。

- 原文身份：标题、原始 URL、发布及联署机关、文号、文件类型、附件、取得时间。
- 主题与范围：可多选主题、地区、行业、机构及业务对象、具体资格条件。
- 状态与时点：政策阶段、原文披露的有效状态、成文日、公开日、施行日、申报截止、过渡期、到期日。
- 实质条款：工具、参数、金额、币种、单位、期限、统计口径与来源条款。
- 关联证据：草案、意见反馈、正式文件、旧版、解读、细则、操作、执行报告和评估。

“影响资产、传导路径、是否超出预期、市场已经计价多少”属于分析层，需要独立证据、时点与依据。没有可靠预期数据时保持未知，不由模型填写一个市场共识。

## 6. 首期建设顺序

1. 补齐规则链：央行、财政、证监会、金融监管总局、外汇局的正式文件、草案、反馈、配套及有效目录。
2. 补齐操作链：央行工具操作、财政收支与债券发行、监管许可与处罚，跟踪有数据支持的落实动作。
3. 补齐产业和地域：发改、工信、商务、税务及关税，再按关注行业选择重点地方；不把全国所有城市设为首期覆盖目标。
4. 政策卡片先呈现“改了什么、何时实施、适用于谁、执行到哪一步、下一项可核验的证据”。每个判断可回到原文或附件。

本轮已将通过验证的订阅配置导入预览；受限入口未启用。未启动持续采集和真实模型调用。后续扩大覆盖时继续验证分页、附件、版本关联与重复来源。

### 条款、项目和问题的关联

1. **条款级状态**：文件整体有效时，也可能有条款暂缓、例外或不同施行日期。例如[上交所2026年交易规则发布通知](https://big5.sse.com.cn/site/cht/www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)另外提供暂缓实施条文附件。不可只保存文件整体生效日。
2. **项目级落地**：用项目代码或公告编号连接招标、中标、合同、变更及验收；付款和企业收入确认分别找依据，不预设先后或从合同金额推算收入。
3. **执行反证**：关联流标、撤销、延期、预算调整、资金闲置、审计问题及整改结果。每项重要政策保存已披露目标、已落实结果、未取得证据；未取得证据不标为目标未完成。
4. **前置条件**：保存资金来源、地方配套、资格、许可和技术条件；明确哪个条件尚未获得公开证据。审批、环评、用地等手续可能并行，不强行拼成固定流程。
5. **原文变化**：保存取得时间、内容版本、附件版本、原始公开日期与页面更新日期；区分网页重刊和政策新发布。
6. **覆盖完整性**：保存最近成功读取、分页范围、历史起点、失败及缺失。无新内容与采集失效是不同状态。例如[发改委文件库](https://www.ndrc.gov.cn/xxgk/wjk/index.html?tab=gg)明确查询只显示最新500条，不能据此宣称已覆盖全部历史政策。

扩展顺序建议先接市场自律规则、公共资源交易、审计整改，再按产业接项目审批与境外贸易限制。每个观察专题至少关联一份正式规则、一类操作证据、一类结果或反证资料。

## 9. 本轮验收

2026-10-03：新增人工相关性审核入口后，574项后端测试通过。预览数据库已导入60个启用来源、55个主题及74条真实资料；19篇已核对原文、摘要与标签，其中政策16篇、财政数据1篇、资金流2篇，精选7篇。所有人工修正经过版本检查与审计，精选分数为空，不伪造模型评分；按既有180秒发布门槛自然释放，保留原始发布时间，不把历史回填当今日新消息。持续采集和真实模型调用保持关闭。

后续手动审核可在后台内容页设置「行业相关性」为通过，再保存标题、摘要、分类和标签；是否进入精选另行判断。清除相关性修正后恢复继承分析结果，屏蔽或待判断会移出动态与精选。模型配置完成后可运行标准自动采集和处理流程。

恢复精选布局后，类型检查、网站构建、35项前端测试及站点冒烟检查均通过；实际页面已验证7条精选、19篇动态、16篇政策，以及「财政政策＋已生效」组合。精选仍包含政策、资金流与披露数据，政策专属主题和标签筛选位于动态政策分类。

## 10. 执行计划后的来源与覆盖改进

配置目录现为68个来源，其中67个启用普通官方HTTP采集，人大法律目录1个暂停待接通；全部继续关闭站内及分发全文。动态政策页的来源覆盖状态由 `/api/site/policy-sources` 实时读取，实际新增与待复核数量以该接口和后台为准。采集与公开分开：新材料进入待核队列，来源官方或采集成功不意味着自动进入政策动态或精选。

本轮补齐并使用项目解析器核验7个可采来源：

- [证监会令](https://www.csrc.gov.cn/csrc/c101953/common_list.shtml?channelid=cd11df89f5894c1eac37ae37cc11e369)与[证监会公告](https://www.csrc.gov.cn/csrc/c101954/common_list.shtml?channelid=625a2f95cc104c1d8b646f98d9f87470)：官网列表脚本指明公开 `searchList` JSON，每次最多2页、36条；原始公告和正式规章分别订阅。
- [深交所规则目录](https://investor.szse.cn/lawrules/index.html)：只读取最新规则区的10条官方记录；其链接标题藏在每行脚本字面值中，专用解析器读取字段而不执行脚本。已验证规则详情与附件入口，静态窗口不代表全部有效及废止规则。
- 金融监管总局[公开征求意见](https://www.nfra.gov.cn/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=951&pageSize=18&pageIndex=1&orderBy=builddate)、[总局机关行政许可](https://www.nfra.gov.cn/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=4110&pageSize=18&pageIndex=1&orderBy=builddate)与[总局机关行政处罚](https://www.nfra.gov.cn/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=4113&pageSize=18&pageIndex=1&orderBy=builddate)：官网导航与JSON明确对应951、4110、4113，每次最多2页、36条。旧父栏目930/931首屏为2019年档案，已避开；总局机关来源不代表地方派出机构全部覆盖。
- [财政部经济建设司民航发展基金](https://jjs.mof.gov.cn/zxzyzf/mhfz/)：专项转移支付预算分配、绩效目标与附件，按360分钟更新。预算下达及绩效目标不等于资金到账、项目完成或目标达成；这是一个明确资金类别的有限目录，不能宣称全部财政专项资金覆盖。

原有金融监管总局部门规章、规范性文件及其他政策3源，也已通过有审计记录的配置更新增加最多2页近期窗口。公开覆盖状态分别保存最近尝试、最近成功、最近失败、原文最新发布日期、实际入库日期范围、发现/新增/正文修订数及分页上限；无新增与失败明确分开，未采集的来源不显示成功时间。

人大法律库已从[官网](https://flk.npc.gov.cn/search)前端定位公开列表 `POST /law-search/search/list` 与详情 `GET /law-search/search/flfgDetails`。完整公开请求经普通curl核验，可取得公布日、施行日、原文机关、文种、版本ID、历史沿革与时效状态（4尚未生效、3有效、2已修改、1已废止）。项目自报FinPulseBot请求实测403，因此 `npc-financial-laws` 保持暂停，不能宣称已自动接通。其准备配置只取2页近期经济金融标题记录，并保留原始元数据；原文可能是OFD/DOCX、详情 `content` 为空，未读取附件时不生成政策事实或版本差异。

另外核验了财政部困难群众救助资金目录：其中2026年分配通知的列表、网页PubDate和公开日期仍写2025-04-10，正文成文为2026-04-10且URL为202604。这一公开日期冲突已记入受限入口，未把它当最新政策启用。审计署列表仍返回502；两者保留为后续逐条核验目标，不用替代窗口掩盖缺口。

采集窗口与正文修订、重复来源身份、RSS条件请求及免费采集边界已通过本地测试；测试只使用本地替身。法律目录元数据变化只刷新原始观察记录，不伪造正文版本，不替代管理员政策事实核对。
